# Projektuppgift, DT071G - CUTE MONSTER QUEST
Detta är en projektuppgift i _Webbutveckingsprogrammet_ på Mittuniveristetet.

Cute Monster Quest är ett enkelt turordningsbaserat monsterspel utvecklat i C# med .NET och Windows Forms. Spelaren väljer ett av tre monster och möter sedan en slumpmässigt vald motståndare.

## Funktioner
 * Välj mellan tre olika monster med olika egenskaper.
 * Möta en slumpmässig motståndare.
 * Turbaserat logik.
 * Fyra olika handlingar:
   * Attack: Attackera motståndaren.
   * Specialattack: Utför en kraftigare attack som kan användas en gång per strid.
   * Skydd: Skydda monstret och minska inkommande skada.
   * Ät bär: Återställ 20 HP.
* Spelet avslutas när något av monstren förlorat all sin HP.

## Starta projektet
 * Ladda ner eller klona projektet från GitHub.
 * Öppna projektets .sln-fil i Visual Studio 2022 eller senare.
 * Kontrollera att .NET desktop development och projektets .NET-version är installerade (.NET 10).
 * Starta spelet genom att trycka på F5 eller klicka på Start i Visual Studio.

**Observera: Projektet använder Windows Forms och behöver köras på Windows.**
